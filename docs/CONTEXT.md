# TalentSphere AI — Project Context

## Purpose & Overview
TalentSphere AI is an enterprise **AI-Powered Recruitment Decision Support Platform** designed to modernize technical hiring. Traditional ATS platforms rely heavily on simplistic keyword matching, which fails to distinguish practical software engineering competency from polished resume buzzwords. 

TalentSphere AI bridges this gap by synthesizing:
1. **Multi-Source Evidence Verification**: GitHub commits, open-source repositories, LeetCode / competitive programming history, and live project deliverables.
2. **Standardized Online Assessments (OA)**: Algorithmic problem solving, code quality metrics, concurrency challenges, and proctored execution.
3. **Explainable AI Reasoning**: Detailed factor breakdowns (Skills 30%, Experience 25%, Projects 20%, OA 15%, Consistency 10%) rather than black-box recommendations.
4. **Human-in-the-Loop Recruiter Control**: Recruiter override capabilities with mandatory audit logging and rationale capture.
